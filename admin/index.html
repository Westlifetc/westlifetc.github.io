웨라쌤 사이트 관리

관리자 연결 후 별도의 관리 화면으로 이동합니다.

처음이라면 토큰 만드는 법
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens로 이동합니다.
  2. Repository access에서 westlifetc.github.io 저장소만 선택합니다.
  3. Repository permissions → Contents: Read and write 권한을 줍니다.
  4. 생성된 토큰은 이 페이지에만 입력하고, 다른 사람에게 보내지 마세요.

토큰은 비밀번호처럼 취급하세요. 공용 PC에서는 ‘기억하기’를 체크하지 마세요.
